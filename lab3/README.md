# Лабораторна робота №3

**Тема:** Блочна верстка макету сайту за допомогою HTML і CSS.
**Виконав:** Рябокінь Дмитро Олександрович, ІС-41.
**Варіант:** 8, як уточнено для попередньої лабораторної. Номер у загальному списку — 129.

## Запуск

Розпакуйте всю папку `lab3` і відкрийте `index.html` у браузері. Посилання над макетом перемикає версії. Сервер, JavaScript, сторонні бібліотеки та встановлення пакетів не потрібні.

## Файли

- `index.html` — верстка через float.
- `flex.html` — верстка через Flexbox.
- `common.css` — спільні кольори, ширини, висоти та оформлення.
- `float.css` — плаваючі колонки, clearfix і центрування без Flexbox.
- `flex.css` — компонування та центрування засобами Flexbox.

## Відповідність макету

Відтворено варіант 8 зі сторінки 18 методички: блакитна верхня смуга, три колонки (зелена IMG, жовта IMG, рожева TEXT), світло-помаранчева нижня смуга. IMG і TEXT — позначки областей зі зразка, а не несправні або незавантажені зображення.

Ширини колонок — 30%, 40%, 30%; верхній і нижній блоки мають ширину 100%. Висоти — 12%, 76%, 12% від макету висотою 500px. На вузьких екранах висота зменшується до 360px, а розташування блоків зберігається. Пропорції й кольори відтворено приблизно за скріншотом, оскільки точних числових значень у методичці немає.

У першій реалізації колонки розміщуються через `float: left`. Псевдоелемент із `clear: both` завершує обтікання; нижній блок також має `clear: both`. Ширини задано у відсотках. Flexbox і Grid не використовуються.

У другій реалізації зовнішній контейнер має `display: flex` і `flex-direction: column`, а середня частина — горизонтальний flex-контейнер. `flex-shrink: 0` зберігає задані розміри. `align-items` і `justify-content` центрують підписи. Float не використовується.

## Перевірка вручну

20.11.2026 виконано валідацію обох HTML-файлів та обох наборів CSS (спільний файл + файл способу). Результат W3C для кожної перевірки: 0 помилок, 0 попереджень. Відповіді сервісів додано до папки лабораторної. Вигляд сторінок у браузері та розташування сторінок звіту Word автоматично не перевірено; звіт потребує скріншотів перед здачею.

1. Відкрийте обидві версії та порівняйте їх із варіантом 8 методички.
2. Перевірте порядок кольорових областей і підписи.
3. Зменште ширину вікна: макет має залишитися в межах сторінки.
4. Зробіть скріншоти обох реалізацій для звіту.
