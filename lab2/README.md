## Завдання 1

Таблиця відтворює варіант 8 зі сторінки 8 методички та приклад на сторінці 9. Вона має 5 базових колонок і 3 рядки. Дві перші колонки вдвічі вужчі за кожну наступну.

- У першому рядку дві порожні комірки, прізвище з `rowspan="2"`, ім’я та по батькові з `rowspan="2"`.
- У другому рядку група займає дві колонки (`colspan="2"`), а номер лабораторної та варіант записано разом у комірці під ім’ям, як у прикладі методички.
- У третьому рядку дві порожні комірки з `colspan="2"` та `colspan="3"`.

Стилі таблиці містяться в елементі `style` у файлі HTML. Для номера 8 використано двозначне значення `08`: перший рядок — `#088f8f`, другий — `#f5f508`. Текст чорний. На `:hover` кольори фону й тексту міняються місцями. Комірки з `rowspan` належать першому рядку, тому реагують на наведення як частина першого рядка.

## Завдання 2

Зображення — два квадрати із чорними рамками та заокругленими кутами. Нижній правий квадрат має напівпрозорий фон, тому в області перетину кольори змішуються. Зображення побудовані лише з HTML-елементів і CSS, без файлів зображень, SVG, canvas або JavaScript.

1. `position`: контейнер із `position: relative`, квадрати з `position: absolute`, координати задано через `top` і `left`.
2. `transform`: звичайні блоки зміщено через `translate`. Висота першого квадрата — 140px, тому другий переноситься на -65px по вертикалі, щоб отримати кінцеву координату 75px. У цьому способі `position` не використовується.

Стилі зображень збережено в окремому файлі `style.css`.

Перевірки виконано 20.11.2026:

- W3C CSS Validator, профіль CSS3: 0 помилок, 0 попереджень для стилів таблиці й окремого CSS-файлу разом (`css-validation.xml`).
