## Запуск

Розпакуйте всю папку `lab6`, відкрийте `index.html` у браузері та натисніть «Завантажити користувачів». Потрібен інтернет. Збережіть поруч `style.css`, `api.js` і `script.js`. Встановлення залежностей не потрібне.

Якщо браузер обмежує запити з локальних файлів, відкрийте папку через VS Code Live Server або за наявності Python виконайте в цій папці `python -m http.server 8000` і відкрийте http://localhost:8000 . На GitHub Pages сторінка працює через HTTPS. Недоступність API, мережеві обмеження чи блокування CORS показуються як помилка запиту; фіктивні дані не підставляються.

## Реалізація

Запит: `https://randomuser.me/api/?results=5&inc=picture,location,cell,name`.

- `results=5` задає п’ять користувачів, як у прикладі методички.
- `inc` обмежує відповідь потрібними групами полів. Місто та індекс вкладені в `location`, тому запитується ця група.
- `fetch()` повертає Promise. У першому `.then()` перевіряється `response.ok`, потім викликається `response.json()`.
- Наступний `.then()` розбирає `results` і готує поля для карток.
- `.catch()` обробляє помилки, `.finally()` відновлює стан кнопки. `AbortController` обмежує очікування 15 секундами.
- Поля картки: `picture.large`, `location.city`, `location.postcode`, `cell`, `name.first` + `name.last`. Відображаються саме в порядку рядка варіанта, фото першим та ім’я останнім.
- Значення вставляються через `textContent`. Індекс підтримує числа та рядки. Відсутні поля отримують підпис «Немає даних», невдале фото — «Фото недоступне».
- Під час запиту кнопка заблокована. Успішний повторний запит замінює картки; невдалий залишає попередні та показує помилку.

Структура: `api.js` — мережевий запит і розбір JSON; `script.js` — подія кнопки й створення DOM; `style.css` — оформлення карток. JavaScript-бібліотеки не використовуються.
