Після успішної перевірки браузер відкриває окреме вікно з введеними значеннями. Якщо воно заблоковане, сторінка показує пояснення: дозвольте спливні вікна для цієї сторінки та повторіть перевірку.

## Регулярні вирази

| Поле | Перевірка |
| --- | --- |
| ПІБ | Українське прізвище змінної довжини, пробіл, два великі ініціали з крапками; підтримано апостроф і дефіс |
| Варіант | Рівно дві цифри; розраховане значення форми — `09` |
| Група | Дві великі українські літери, дефіс, дві цифри: `ІС-41` |
| Факультет | Чотири великі українські літери, наприклад `ФІОТ` |
| Дата | `ДД.ММ.РРРР`; додатково перевіряється кількість днів у місяці та високосний рік |

Шаблон ПІБ із методички трактовано як прізвище та ініціали, без обмеження прізвища шістьма літерами. Пробіли на початку та в кінці значень прибираються. Поле варіанта перевіряє формат двох цифр, а не відповідність особі; загальний номер 129 показано окремо.

Форма має `novalidate`, щоб саме JavaScript через регулярні вирази виконував усі перевірки та підсвічував кожне неправильне поле. Дані не надсилаються на сервер. Результат вставляється через `textContent`, а не як HTML.

## Таблиця

36 клітинок пронумеровано послідовно по рядках. Активна клітинка **21**: четвертий рядок, третій стовпець.

- `mouseenter`: випадковий колір лише клітинки 21.
- `click`: колір клітинки 21 змінюється на обраний у палітрі.
- `dblclick`: клітинки того самого стовпця, починаючи з обраної, через одну — **21 та 33** — отримують колір із палітри.
- «Скинути кольори»: повертає всі клітинки до початкового вигляду.

Інші клітинки не мають цих обробників. При подвійному кліку браузер також генерує одиночні кліки, але вони не змінюють кінцевого результату: клітинка 21 входить до обох операцій. Текст автоматично стає чорним або білим залежно від кольору фону.

Для клавіатури: Tab до клітинки 21; Enter/пробіл — одиночна дія, Shift + Enter — дія подвійного кліку.
